# ملاحظات إصدار Stage 11 — ERP Global Pro

## ملخص

تركّز هذه النقطة على خدمات التجارة والمدفوعات: المبيعات والمشتريات والمستندات والمرتجعات والدفعات وتطبيق الأرصدة وPOS وكشوف الحساب وأعمار الديون.

## التوافق

- لا يتطلب هذا التغيير ترحيلًا جديدًا لقاعدة البيانات.
- يظل مخطط SQLite عند الإصدار 6.
- يجب أن يستمر تمرير `company_id` صراحةً في أي استدعاء من مهمة خلفية أو CLI؛ أما طلب HTTP فيحصل على الشركة من سياق JWT والعضوية الموثق.
- لا تُرسل `company_id` من العميل كمصدر للثقة.

## قبل الاستخدام

1. احتفظ بنسخة احتياطية من قاعدة البيانات.
2. شغّل اختبارات المشروع في بيئة تحتوي على متطلبات `backend/requirements.txt`.
3. نفّذ اختبارات HTTP والتكامل الفعلية قبل أي نشر.
4. أبقِ بوابة تعدد الشركات مغلقة حتى اعتماد بقية الخدمات ومراجعة Release Gate.

## غير مشمول

هذه النقطة لا تعني اكتمال عزل كل النظام، ولا تشمل اعتماد PostgreSQL/RLS أو تشغيل متعدد الشركات في الإنتاج.
